# BloodChain

A web platform for blood donation management and traceability, built on a microservices architecture with Ethereum blockchain for immutable bag tracking.

| Member | Role | Branches |
|---|---|---|
| **Finamou** | Frontend · DevOps | `feature/finamou-*` |
| **Tenguh** | Backend · Blockchain | `feature/tenguh-*` |

## Tech Stack

| Layer | Technology |

## Getting Started

### Prerequisites

- Python 3.11+
- Node.js 18+ (for Hardhat / smart contracts)
- Docker & Docker Compose
- Git

### 1. Clone the repository

```bash
git clone https://github.com/your-org/bloodchain.git
cd bloodchain
```

### 2. Set up environment variables

```bash
cp .env.example .env
# Edit .env and fill in:
# DATABASE_URL, REDIS_URL, SEPOLIA_RPC_URL, CONTRACT_ADDRESS ...
```

### 3. Run locally with Docker Compose

```bash
docker compose up --build
```

The app will be available at `http://localhost:8000`

### 4. Run database migrations

```bash
docker compose exec web python manage.py migrate
```

### 5. Deploy Smart Contracts (Sepolia testnet)

```bash
cd blockchain
npm install
npx hardhat run scripts/deploy_blood_unit.js --network sepolia
npx hardhat run scripts/deploy_rewards.js --network sepolia
```

## Branch Workflow

> Always start from `dev`. Never commit directly to `main` or `dev`.

```bash
git checkout dev
git pull origin dev
git checkout -b feature/your-name-task-name

# ... do your work ...

git add .
git commit -m "feat: short description of what you did"
git push origin feature/your-name-task-name
# Then open a Pull Request → target: dev on GitHub
```

### Commit message convention

| Prefix | Use for |
|---|---|
| `feat:` | New feature or file |
| `fix:` | Bug fix |
| `chore:` | Setup, install, scripts |
| `docs:` | Documentation, README |
| `ci:` | Jenkins, pipeline changes |
| `test:` | Adding or fixing tests |
| `style:` | UI polish, CSS changes |

## Running Tests

```bash
# Python unit + integration tests
docker compose exec web python manage.py test

# With coverage report
docker compose exec web coverage run manage.py test
docker compose exec web coverage report

# Smart contract tests
cd blockchain && npx hardhat test
```

## CI/CD Pipeline

Every push to a `feature/*` branch triggers Jenkins automatically via GitHub webhook:

1. **Build** — builds the Docker image
2. **Test** — runs unit and integration tests
3. **Deploy** — deploys to K3s cluster (on merge to `dev` or `main`)

Jenkins dashboard: `http://your-vps-ip:8080`
